Connect Creem in an afternoon

一个下午接好 Creem

  1. Create a Creem account and toggle Test Mode. Copy the test API key from Developers.
  2. 注册 Creem，打开 Test Mode，在 Developers 复制测试 API key。
  3. Create a product (one-time for this $49 storefront, or recurring for your SaaS). Copy the prod_… id.
  4. 创建一个产品（本落地页买断用 one-time，你自己的订阅产品用 recurring），复制 prod_… 编号。
  5. Set webhook URL to https://your-api/api/webhooks/creem and copy the signing secret.
  6. Webhook 填 https://你的域名/api/webhooks/creem，复制签名密钥。
  7. Put keys in .env. For this landing page, paste the Share payment link into site/config.js.
  8. 把密钥写入 .env。卖这个落地页时，把 Share 支付链接贴进 site/config.js。

FAQ

Why Creem instead of Stripe? 为什么不用 Stripe？

Stripe often declines accounts for China-based and some cross-border sellers. Creem acts as Merchant of Record: tax, checkout, and payouts, with a REST API close enough that a small starter can ship.

Stripe 经常拒掉国内及部分跨境卖家。Creem 作为 Merchant of Record 处理税务、结账和结算，REST API 足够让一套起步模板直接上线。

Is $49 a subscription? 49 美元是订阅吗？

No. Shipnet itself is sold as a one-time download of this codebase. Your own product can be one-time or recurring — that is configured on the Creem product, not hardcoded here.

不是。Shipnet 本身是买断源码。你自己的产品做一次性还是订阅，在 Creem 产品里配置，不写死在代码里。

Do I need to keep your branding? 必须保留你们的品牌吗？

No. Replace copy, colors, and the sample “lanes” feature. Keep the MIT license file. You own the running service you deploy.

不用。文案、配色和示例「航线」功能都可以换。保留 MIT 许可证文件。你部署出去的服务归你。
