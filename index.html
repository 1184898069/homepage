  1. 一

    九合一数据平台后端

    独立完成C# / ASP.NET Core两千余次提交

    这是我一个人从架构到业务写完并持续迭代的主项目。九个分析产品收成同一套 API：银行流水、税票发票、通信话单、出行轨迹、案件库、层级/传销画布、综合分析、动态检索，以及完整的手机画像。解决方案里九个工程，六十多个控制器，提交两千多次。

    • 分层自己定：控制器、服务、DAO、领域模型、分析模型、公共库、测试。自定义 Token 鉴权、全局授权、异常过滤，路由统一，Swagger 跨程序集出文档。权限另有独立的 SQL 版本库。
    • 存储四套一起用：PostgreSQL（SqlSugar）、Elasticsearch（含库表融合检索）、Neo4j 图库、SQLite 本地参考库（基站、汇率、IP 归属）。批量上传支持断点续传，长任务有进度接口，大文件走 Git LFS。
    • 银行流水、税票、话单都能进、能标、能碰撞；税票有碰撞分析，银行卡有 MAC 碰撞、轨迹和对账单生成。资金分析覆盖流入流出、明细弹出、按币种汇总。
    • 手机画像是一整条产品线，不是几个接口：即时通讯、邮件、电商、出行导航、浏览分类、网络共享、本机信息；证据树导航；跨证据全文检索和滚动导出；聊天词画像和停用词；敏感信息一键挖掘；按时段、时序、直接关系展开。单机版能打成 Windows 服务离线跑。
    • 关系图谱是自己写的图引擎：点线合并、按方向连边、去重、样式和图上唯一 ID，按文档注释能吃下很大的明细索引。图标调色板、SVG 导入、可视化条件都在同一套里。
    • 人脸登录（检测后人脸向量核验）、第三方取证报告格式映射、缓刑等规则模型自动匹配日期。Excel / Word / CSV / 分析报告 / 页眉页脚 PDF 都能出；现场授权走加密狗和机器码。
    • 配套也是我写的：ES 索引升级工具、数据比对桌面工具、本地解析库、Vue 前端差异同步小工具。前端是 Vue。有单元和集成测试工程。
