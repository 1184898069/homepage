Selected work

  1. 一

    九合一数据平台后端

    C# / ASP.NET CorePostgreSQL · ES · Neo4jVue

    将银行流水、税票、通信话单、出行轨迹、案件库、层级分析、综合研判和手机画像做成同一套 API。现场只需登入一次，就能在同一权限和同一检索里把多源数据对上、画出来、导出成报告。

    • 实现统一鉴权（Token、角色菜单、部门）和全局异常处理；权限变更走独立 SQL 版本库，避免各模块各搞一套登录。
    • 接入 PostgreSQL、Elasticsearch、Neo4j 和 SQLite 参考库（基站、汇率、IP 归属），库表与 ES 可融合检索。大包导入支持断点续传和任务进度，失败不必从头传。
    • 流水、税票、话单可入库、标注、碰撞；银行卡支持 MAC 碰撞、轨迹和对账单；资金分析给出流入流出、明细下钻和多币种汇总，把「同一主体有没有在别的账单里出现」变成可点的结果。
    • 手机画像覆盖即时通讯、邮件、电商、出行、浏览和本机信息：证据树、跨证据全文检索与滚动导出、聊天词画像、敏感信息一键挖掘、时段与时序、直接关系。单机版可打成 Windows 服务离线运行。
    • 关系图谱支持按条件建图、点线合并、按方向连边和去重，把账单和话单里的关系铺成可操作的画面，而不是导出一张静态图。
    • 人脸核验登录、第三方取证报告格式映射、规则模型按日期自动匹配。分析报告可出 Excel / Word / CSV / PDF（含页眉页脚）。现场用加密狗和机器码授权。
